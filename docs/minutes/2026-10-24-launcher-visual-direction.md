# 検索ランチャーの表示と候補

- ユーザーは独立したNew Tab Launcherウィンドウではなく、Arcのようにブラウザ上へ重ねる検索欄を希望。
- 「新しいタブで検索」「Escで閉じる」などの見出し・説明文は不要。入力欄と候補を中心にする。
- 検索サジェストと既存タブの候補を希望。既存タブを明示的に選択した場合だけ切り替え、通常のEnterは新規タブを優先。
- 通常ページと制限ページの実装上の区別を先にユーザーへ選ばせる説明は意図を伝えられなかった。独立ウィンドウによる代替が希望の体験ではない点を共有済み。
- ユーザーはまず試作するか、先にイメージ画像を出すことを了承。今回は画像で表示の認識を合わせる。
- imagegenスキルと組み込み画像生成ツールを使用し、添付Arcスクリーンショットを参考にプレビューを作成する。実装済み画面と誤認させないようイメージと明示する。
- プレビューを生成し共有。背景のWebページ上に白い検索欄と5行の候補を重ねた案。先頭は入力「東京」の新規検索、次に検索サジェスト、最後に既存タブ2件。説明文・アプリ名・ウィンドウ枠なし。これは表示案であり、まだ実装への反映は行っていない。
- 最終プロンプトの要点：添付Arc画面の構図を参考に、入力欄と検索候補3件・既存タブ候補2件だけを表示する日本語UI。新規検索を初期選択し、検索候補は既存タブより上に並べる。アプリタイトル、OS枠、アドレスバー、見出し、フッター、Esc説明、送信ボタンは禁止。組み込み画像生成を使用。
- ユーザーは生成画像を開けなかったため実装を指示。feat/minimal-overlay-suggestionsで0.2.0を実装した。
- 白いページ内オーバーレイに入力欄と候補のみを表示。見出し・Esc説明・フッター・送信ボタンを削除。先頭は必ず現在の入力による新規検索。検索候補を上、既存タブを下に配置。↓↑とクリックで選択し、明示選択した既存タブだけ切り替える。
- 独立したOSウィンドウの生成とwindow.htmlを削除。Diaの一時的なactiveTab権限への依存を避けるためHTTP/HTTPSサイト権限を追加。既存タブ情報のためtabs権限も追加。Chrome/Dia内部ページでDOM注入ができない制約は残るため、ツールバーのポップアップのみを代替とし、そのポップアップも失敗する場合は別ウィンドウを作らずエラーを残す。
- 検索サジェストはGoogleの公開エンドポイント（保証された拡張機能向けAPIではない）を利用。180ms遅延・Cookieなし・2秒タイムアウト。URLやメールアドレスなどを候補取得先へ送らない。タブタイトルやURLはローカルで検索。入力履歴は保存しない。
- 自動テスト20件が通過。固定語tokyoでサジェスト取得先のHTTP 200とJSON候補10件を確認。
- Browser plugin not availableのためfrontend-testing-debuggingのPlaywright経路を使用。既存Chromiumに実拡張機能を読み込み、サイト権限でページ内表示できること、表示時にウィンドウ・タブが増えないこと、検索候補が出ること、Enterの新規タブ優先と既存タブ明示選択での切り替えを確認。
- テスト時だけ隔離ワールドのShadow DOMを開放して検査。追加の決定的な画面テストで遅い候補応答の破棄、↓キー選択、IME変換確定、Escを確認。1280x800と390x844でスクリーンショットを確認し、はみ出しなし。拡張機能・ローカルのテストページで実行時エラーなし。
- プレビューからの意図的な差分：検索候補を最大4件まで表示し、タブのファビコンは外部から取得せずタイトル先頭文字を表示する。白いカード、丸角、淡い青の初期選択、入力欄と候補のみの構造、検索候補優先はプレビューを維持。
- Diaの実機でのページ内表示はユーザーによる再確認が必要。更新時は追加されたサイト権限・タブ権限の確認が必要になる場合がある。
- Windows側の導入済みフォルダへ0.2.0をコピーし、廃止したwindow.htmlを削除した。既存のAutoHotkey設定は変更していない。

- ユーザーよりDiaの拡張機能ページはdia://extensionsとの補足。Google上では検索欄が表示され、見た目は理想通り、検索も可能と報告。添付画像でもOSの別ウィンドウではないページ内オーバーレイと既存タブ候補を確認。Ctrl+TのAutoHotkey連携については、この報告だけでは確認済みと扱わない。

- ユーザーがAutoHotkeyの代わりにPowerToysを使用できるか質問。Microsoft公式ドキュメントでKeyboard Managerのアプリ別ショートカット再マップを確認。Ctrl+T→Ctrl+Shift+SpaceをDia/Chromeごとに設定でき、PowerToysの起動中のみ有効。READMEに代替手順を追記。実際のPowerToys設定は変更していない。
