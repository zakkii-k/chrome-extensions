# リンクの一時プレビュー拡張

- ユーザーはX等でリンク先をページ上のモーダルとして開き、領域外クリックで閉じる機能を希望。拡大ボタンを押したときだけ通常の新規タブにする。Arcの参考画像を添付。
- 参考機能はArcのPeek。OSの別ウィンドウを出す要望ではない。
- 開くトリガー（全サイトの外部リンクの通常クリック／Shiftクリックのみ／Xの外部リンクだけ通常クリック）について確認中。
- 既存の検索ランチャーとは別の拡張として同じリポジトリ内で管理する構成が適している。
- 実装調査ではiframeによるリンク先表示がサイト側の埋め込み制限（X-Frame-Options、CSP frame-ancestors等）の影響を受けることを確認。Arc本体と同等の全サイト対応を約束しない。参考画像のYahooニュースも実際の表示可否の確認が必要。
