# Changelog

## 0.2.0 — 2026-10-24

初回のGitHub試用版リリース。

- Webページ上に、入力欄と候補だけの検索UIを表示。
- Enterで確定してから新規タブで検索またはURLを開く。同じURLが開いていても既存タブへ自動で切り替えない。
- Googleの検索候補と既存タブの候補を表示。既存タブを明示選択した場合だけ切り替え。
- 日本語変換、キーボード選択、Escによるキャンセルに対応。
- OSの別ウィンドウによる代替表示を廃止。
- PowerToysまたはAutoHotkeyによるWindowsのCtrl+T割り当てに対応。

制限：ブラウザの設定画面や組み込みのNew Tabなど、スクリプト注入が禁止された画面ではページ内表示を利用できません。DiaのGoogleページで表示と検索を確認済み。MacとWindowsのキー変換全体は追加検証が必要です。
