# Privacy

更新日：2026-10-24

Link Peekは、外部リンクを選んだときに、そのURLをブラウザのiframeとして読み込みます。通常のページ閲覧と同じように、アクセス先のサイトにはIPアドレス等の通信情報が届きます。独自のサーバー、分析サービス、広告、テレメトリーは使用しません。

プレビューには `referrerpolicy="no-referrer"` を指定します。ブラウザのCookie・第三者Cookie制限・ログイン状態により、通常のタブと表示が異なる場合があります。これらの制限を解除する処理はありません。

Xの短縮URL（t.co）を選んだ場合は、表示前にCookieなしのリクエストで転送先を取得します。t.coのHTML中間ページが返る場合は、meta refreshまたは固定の転送先文字列だけを読み、JavaScriptは実行しません。通常のHTTP転送で最終URLが分かった場合はレスポンス本文を読みません。t.co以外の通常URLに事前リクエストは行いません。

## 保持する情報

- 一度解決したt.coリンクの行き先は、有効期限5分・最大64件のキャッシュとして実行中のメモリにのみ保持します。永続ストレージには保存せず、service worker終了時に失われます。リンクをクリックする前の先読みは行いません。
- 有効／無効の設定を `storage.local` に保存します。
- 開いているプレビューのURL、表示元のタブとフレームの識別情報を、動作のため `storage.session` に保持します。プレビューを閉じたとき、元のタブを閉じたとき、元ページが移動したときに削除します。ブラウザ再起動後に閲覧履歴として残す用途では使用しません。
- ページ本文や入力フォームの内容は収集・保存・独自サーバーへ送信しません。

## 権限

- HTTP/HTTPSのサイトアクセス：リンクのクリックを検出し、元のページへプレビューUIを表示します。プレビュー先でもEsc操作や別タブ指定リンクの処理を行います。
- `webNavigation`：開いたプレビューの読み込み、拒否、リダイレクト、移動先を識別し、拡大時に現在のURLを使います。
- `storage`：有効／無効設定と、ブラウザ動作中のプレビュー情報に使用します。
- `declarativeNetRequestWithHostAccess`：プレビューの表示元タブ、拡張機能を開始元とするサブフレームに限定して、レスポンスのX-Frame-Optionsを一時的に除外します。閉じる・元ページ移動・タブ終了時にルールを削除し、通常の閲覧や他のタブには適用しません。CSPは変更しません。

iframe内のページにはスクリプト・フォーム・同一オリジン機能を許可し、親タブの移動やポップアップの作成は許可しないsandboxを設定しています。プレビュー先の動作やデータの扱いは、そのサイトのポリシーにも従います。
