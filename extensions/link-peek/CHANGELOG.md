# Changelog

## 0.1.4 — 2026-10-25

- プレビューの元タブ・拡張開始のサブフレームだけでContent-Security-Policy応答ヘッダーを一時除去し、日経・NHKの埋め込み禁止に対応。通常のタブには適用せず、閉じる・元ページ移動・タブ終了時に解除。
- ヘッダー全体を除くためnonceなど他のCSP保護も当該応答では外れることをREADMEとPrivacyに明記。sandbox・Cookie設定・HTML内のmeta CSPは維持。

## 0.1.3 — 2026-10-25

- 拡張機能更新後の古いコンテンツスクリプトでExtension context invalidatedの同期例外が漏れる問題を修正。
- コンテキストが失効した場合は表示中のプレビューを閉じ、クリックを横取りせず元のリンク動作へ戻す。更新後は元ページを再読み込みして新しい処理を適用する。

## 0.1.2 — 2026-10-24

- 解決済みのt.coリンクの行き先を実行中のメモリでキャッシュ（有効期限5分、最大64件）。同時に同じリンクを開く場合もリクエストを共有。失敗結果はキャッシュしない。
- 短縮URL確認とプレビュー用ルールの準備を並行して行い、初回の待ち時間を短縮。リンクを開く前の先読みや、記事の広告・スクリプトの削除は行わない。

## 0.1.1 — 2026-10-24

- Xのt.co中間ページから記事へ移動した際に、プレビュー用ヘッダー例外が適用されなくなる不具合を修正。短縮URLはCookieなしのリクエストでHTTP転送またはHTMLの転送先情報を先に取得し、拡張フレームから直接表示する。
- 意図的な読み込み中断を表示拒否として扱わないよう修正。

## 0.1.0 — 2026-10-24

- 外部リンクの通常クリックでページ内モーダルを表示。
- 領域外クリック・Esc・×で閉じる。
- 拡大時だけ、プレビューの現在のURLを新しいタブで開く。
- 内部リンク、修飾キー、中央クリック、ダウンロードの元の動作を維持。
- X-Frame-Optionsの例外をプレビュー中の拡張フレームだけに限定し、閉じたら解除。CSPは維持。
- CSP等による埋め込み拒否時はエラーを表示し、明示操作でタブへ開く。
- 拡張機能アイコンで有効／無効を切り替え。
