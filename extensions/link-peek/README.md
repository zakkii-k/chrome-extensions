# Link Peek

外部リンクを通常クリックすると、今のページ上でリンク先を一時表示します。外側クリック・Esc・×で閉じ、拡大ボタンを押したときだけ新しいタブにします。検索ランチャーとは別の拡張です。

## 別PCのChrome・Edgeに入れる（Windows）

1. 下のリリースから `link-peek-0.1.4-extension.zip` をダウンロードします。
2. ZIPを右クリックして「すべて展開」。展開先は `ドキュメント\BrowserExtensions\link-peek` など、使い続ける場所にします。
3. Chromeは `chrome://extensions`、Edgeは `edge://extensions` を開き、**デベロッパーモード**をオンにします。
4. **「パッケージ化されていない拡張機能を読み込む」**（Edgeでは「展開して読み込み」などの表記）を選び、`manifest.json` が入ったフォルダを指定します。ZIP自体は選びません。
5. 拡張のサイトアクセスを「すべてのサイト」にし、すでに開いていたWebページを再読み込みします。ChromeとEdgeそれぞれで読み込みます。

リリース：[link-peek 0.1.4](https://github.com/zakkii-k/chrome-extensions/releases/tag/link-peek/v0.1.4)

展開フォルダは使用中も必要なので削除・移動しないでください。ストア配布ではないため自動更新されません。更新時は新しいZIPの内容で同じフォルダを置き換え、拡張一覧の再読み込みボタンを押し、Webページも再読み込みしてください。別PCには同期だけではインストールされません。会社などで管理されたブラウザは、管理ポリシーにより読み込めない場合があります。

## Windowsで使う

このフォルダでWindows PowerShellを開いて実行します。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\windows\prepare.ps1
```

1. Diaの `dia://extensions` またはChromeの `chrome://extensions` を開き、デベロッパーモードを有効にします。
2. 「パッケージ化されていない拡張機能を読み込む」で `%LOCALAPPDATA%\LinkPeek\extension` を選びます。
3. すでに開いていたWebページを再読み込みします。
4. 他のサイトへ移動するリンクを通常クリックします。

補助の常駐ソフトは不要です。拡張機能アイコンをクリックすると有効／無効を切り替えます。`OFF`のときはリンクの元の動作に戻ります。

## 操作と範囲

- 外部のHTTP/HTTPSリンク：プレビュー。同じオリジンのリンクやページ内アンカーは元の動作を維持。
- 領域外クリック、Esc、×：プレビューを閉じる。元のページとタブ数を維持。
- 拡大ボタン：プレビューで現在表示しているURLを新しいタブへ開き、プレビューを閉じる。
- Ctrl／Command／Shift／Altを押しながらのクリック、中央クリック、ダウンロード用リンク：元の動作を維持。
- プレビュー内の通常リンクはプレビュー内で移動。別タブ指定のリンクも、可能な場合はプレビュー内へ移動。

リンクを表す `a` 要素を持たずJavaScriptだけで画面遷移するボタンや、すでにページ側で処理済みの操作には介入しません。インストール後に既存ページの再読み込みが必要です。

## 表示できないサイト

Arc本体のPeekと異なり、拡張機能ではiframeを使います。ログイン・Cookie・サイトの仕様やHTML内のCSPにより、表示できないことがあります。その場合はプレビューできない旨を表示し、「タブで開く」または外側の拡大ボタンで開けます。勝手に新規タブへ切り替えません。

`X-Frame-Options` と `Content-Security-Policy` 応答ヘッダーを、開いているプレビューの表示元タブかつ拡張機能が開始するサブフレームに限定して、一時的なセッションルールで除外します。閉じる・元ページの移動・タブを閉じるとルールを削除します。通常のトップレベル閲覧、他タブ、サイト側のフレームに適用しません。CSPは埋め込み禁止だけでなく、同じ応答ヘッダー内のスクリプト実行元・nonce・Trusted Typesなどの保護も外れます。事前の安全性検証は行いません。HTML内のmeta CSP、iframe sandbox、Cookie設定は変更しません。ブラウザ内部画面、Webストア、PDFなど、拡張機能が実行できない場所では利用できません。

## 開発

```bash
npm test --workspace=@zakkii-k/link-peek
python3 scripts/package_extensions.py link-peek
```

上記はリポジトリルートから実行します。本体の実行に外部ライブラリやサーバーは不要です。
