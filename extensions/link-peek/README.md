# Link Peek

外部リンクを通常クリックすると、今のページ上でリンク先を一時表示します。外側クリック・Esc・×で閉じ、拡大ボタンを押したときだけ新しいタブにします。検索ランチャーとは別の拡張です。

## Windowsで使う

このフォルダでWindows PowerShellを開いて実行します。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\windows\prepare.ps1
```

1. Diaの `dia://extensions` またはChromeの `chrome://extensions` を開き、デベロッパーモードを有効にします。
2. 「パッケージ化されていない拡張機能を読み込む」で `%LOCALAPPDATA%\LinkPeek\extension` を選びます。
3. すでに開いていたWebページを再読み込みします。
4. 他のサイトへ移動するリンクを通常クリックします。

補助の常駐ソフトは不要です。拡張機能アイコンをクリックすると有効／無効を切り替えます。`OFF`のときはリンクの元の動作に戻ります。

## 操作と範囲

- 外部のHTTP/HTTPSリンク：プレビュー。同じオリジンのリンクやページ内アンカーは元の動作を維持。
- 領域外クリック、Esc、×：プレビューを閉じる。元のページとタブ数を維持。
- 拡大ボタン：プレビューで現在表示しているURLを新しいタブへ開き、プレビューを閉じる。
- Ctrl／Command／Shift／Altを押しながらのクリック、中央クリック、ダウンロード用リンク：元の動作を維持。
- プレビュー内の通常リンクはプレビュー内で移動。別タブ指定のリンクも、可能な場合はプレビュー内へ移動。

リンクを表す `a` 要素を持たずJavaScriptだけで画面遷移するボタンや、すでにページ側で処理済みの操作には介入しません。インストール後に既存ページの再読み込みが必要です。

## 表示できないサイト

Arc本体のPeekと異なり、拡張機能ではiframeを使います。CSPの `frame-ancestors` による埋め込み禁止や、ログイン・Cookie・サイトの仕様により、表示できないことがあります。その場合はプレビューできない旨を表示し、「タブで開く」または外側の拡大ボタンで開けます。勝手に新規タブへ切り替えません。

`X-Frame-Options` のみ、開いているプレビューの表示元タブかつ拡張機能が開始するサブフレームに限定して、一時的なセッションルールで除外します。閉じる・元ページの移動・タブを閉じるとルールを削除します。通常のトップレベル閲覧、他タブ、サイト側のフレームに適用しません。CSPやCookie設定は変更しません。ブラウザ内部画面、Webストア、PDFなど、拡張機能が実行できない場所では利用できません。

## 開発

```bash
npm test --workspace=@zakkii-k/link-peek
python3 scripts/package_extensions.py link-peek
```

上記はリポジトリルートから実行します。本体の実行に外部ライブラリやサーバーは不要です。
